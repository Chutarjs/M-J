# Audios y videos

Podés agregar archivos locales para las cartas o los viajes.

- Para una carta: en `mensajes.js`, añadí por ejemplo `audio: 'assets/media/day-07.mp3'` o `video: 'assets/media/day-07.mp4'` dentro del día 7.
- Para México o Guatemala: editá cualquier recuerdo en `recuerdos.js`, usando rutas como `assets/media/mexico-risa.mp3`, `assets/media/guatemala-atardecer.mp4` o `assets/images/mexico-01.jpg`.

Usá preferiblemente MP3 para audio y MP4 (H.264) para video, porque son los formatos que mejor funcionan en navegadores y GitHub Pages. No subas videos enormes: comprimilos antes para que el repositorio siga liviano.
